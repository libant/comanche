# Comanche

## Overview

An analysis of concert ticket prices in New York City, applying predictive modelling to assess whether temporal proximity to a concert, artist popularity, or a combination of both explains price variation, replicating the framework of Haglund (2020) *What Makes The Market Tix* using Ticketmaster data.

## File Structure

The repo is structured as:

- `data` contains the dataset that was constructed, stored as a SQLite database (`comanche.db`) and the spreadsheet data that was analyzed.
- `model` contains the models and figures generated by the analysis scripts.
- `paper` contains the PDF of the paper.
- `scripts` contains the Python scripts used to simulate, download, clean, test, and model the data.
